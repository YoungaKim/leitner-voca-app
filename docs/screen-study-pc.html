03-UXUI.md §3.3 반영 — 학습 세션은 PC에서도 사이드바·하단 탭 없이 전체화면 포커스로 진입(딴 데 신경 못 쓰게). 넓은 화면을 활용해 카드 폭을 넓히고 키보드 단축키(§0-1 PC 특화 여지)를 노출. 위: 제시+힌트 단계 · 아래: 정답 확인 단계 (발음 자동재생 + 청크/문법 메모 + 자기 채점). 진행 바 아래 내 상자 미니 스트립을 상시 노출해, 학습 도중에도 전체 상자가 얼마나 차 있고 지금 카드가 어디 있는지 계속 보여준다 — 세션 중에도 라이트너 특유의 진척 체감이 끊기지 않게.
