## 발견 문제와 조치

1. **Android 인증 정보 노출:** SDK 예외에 HTTP Authorization 토큰·요청 정보가 포함됐고 UI가 그대로 표시했다. 저장 오류를 고정 안내로 변환하고 충돌에 홈 복귀·재동기화를 안내하도록 수정했다. 로그인·읽기·질문·시트 요청 오류도 예외 전문을 UI/공유 syncState에 전달하지 않도록 변경했다. 수정 APK의 오프라인·충돌 재현에서 비노출 확인.
2. **기존 운영 웹 탭과 비교 탭 로딩:** 사용자 허용 후 기존 탭 새로고침으로 정상화됐다. IndexedDB 캐시 버전 전환 차단과 부합하나 별도 계측으로 원인을 확정하지 않았다.
3. **초기 일시 실패:** Android 최초 Supabase 요청 시간 초과와 로컬 최초 읽기 실패는 재시도·재동기화 후 복구됐다. 간헐적 실패 자체가 해결됐다고 판정하지 않는다.

## 미검증·제한

- TC-SYNC-05~08, 10, 12~14 등의 모든 시나리오를 실제 다기기 UI에서 실행하지 않았다. 일부는 기존 단위/mock/DB 검증으로만 확인했다.
- 테스트 계정 UI는 pool0인 수동 카드 기반이다. 시트 가져오기·동시 pool 도입·일일 신규 한도 경계는 별도 UI 검증이 필요하다.
- 웹 실제 오프라인 주입, Android 모든 CRUD/읽기 실패, 모든 갱신 트리거 조합은 미검증이다.
- Android 홈에 웹의 이동 이벤트 집계 행이 없어 동일 표시를 비교하지 않았다.
- 세션 위치·미저장 답·힌트·웹 origin별 채점 미반영 다시보기 목록은 공통 상태 검수 범위 밖이다.
- 실제 사용자 Android 기기 설치·사용은 에뮬레이터 결과에 포함하지 않는다.
