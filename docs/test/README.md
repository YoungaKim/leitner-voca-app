# 날짜별 검수 결과

실행 결과는 **검수 날짜 기준** `docs/test/YYYY-MM-DD/결과서.md`에 저장한다. 같은 날의 후속 검증은 해당 결과서에 추가하고 증거 화면은 같은 날짜의 `images/`에 보관한다.

절차·기대 동작은 [테스트 케이스](../05-TEST-CASES-MVP1.md)에 유지한다. 결과서에는 실행 범위, 통과·실패·미검증 구분, 수정·배포 버전을 기록한다. 단위/mock/DB 검증을 실제 다기기 UI 검증과 구분한다.
