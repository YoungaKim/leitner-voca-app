# MVP1 테스트 케이스

> `04-PLAN.md`의 "확인 방법(비개발자용 체크리스트)"를 실행 가능한 테스트 케이스로 구체화한 문서.
> CSV 가져오기 케이스는 `sample-data/test-fixtures/*.csv` 픽스처 파일과 짝을 이룬다.

## 1. 화면 흐름

| ID | 목적 | 사전조건 | 단계 | 예상 결과 |
|---|---|---|---|---|
| TC-01 | 앱 최초 진입 | 브라우저 데이터 없음(시크릿 모드) | `localhost:5173` 접속 | 검은 화면 없이 홈 화면 표시 |
| TC-02 | 단어장 생성 | 홈 화면 | 단어장 메뉴 → 이름 입력 → 생성 버튼 | 목록에 새 단어장이 즉시 표시 |
| TC-03 | 카드 수동 추가 | 단어장 1개 존재 | 단어장 상세 → 카드 2~3개 직접 입력 후 추가 | 목록에 추가한 카드가 표시 |
| TC-04 | 학습 세션 진행 | 오늘 복습할 카드 ≥1 | 홈 → [학습 시작] → 힌트 확인 → 정답 확인 → 알았어/몰랐어 선택 | 한글 문장 → 힌트 → 정답 → 채점 흐름이 끊김 없이 진행 |
| TC-05 | 세션 요약 | 학습 세션 완료 | 마지막 카드 채점 후 대기 | "오늘 몇 개 맞았는지" 요약 화면 표시 |
| TC-06 | 새로고침 후 상태 유지 | TC-04에서 채점 완료 | F5 새로고침 → 해당 카드의 박스 확인 | 박스 승급/강등 결과가 유지됨(초기화 안 됨) |
| TC-07 | 브라우저 간 비공유 확인 | TC-02~04 데이터 존재 | 다른 브라우저(또는 새 시크릿 창)로 접속 | 단어장/카드가 보이지 않음(로컬 저장이므로 정상) |

## 2. CSV 가져오기 (`apps/web/src/lib/csv.ts`)

각 케이스는 `sample-data/test-fixtures/` 아래 동일한 이름의 CSV로 재현한다.

| ID | 픽스처 파일 | 목적 | 단계 | 예상 결과 |
|---|---|---|---|---|
| TC-CSV-01 | `csv-valid-basic.csv` | 정상 가져오기 | 단어장 상세 → CSV 가져오기 → 파일 선택 | 오류 없이 5행 모두 New Pool로 흡수, "N개 가져옴" 메시지 표시 |
| TC-CSV-02 | `csv-quoted-commas.csv` | 큰따옴표로 감싼 셀 안의 콤마 파싱 | 위와 동일 | 콤마가 포함된 한글/영어 문장이 필드 분리 없이 한 셀로 정상 저장 |
| TC-CSV-03 | `csv-duplicate-ids.csv` | 이미 가져온 id 재가져오기 dedupe | ① 파일을 한 번 가져와 t001을 이미 가져온 상태로 만든 뒤 ② 같은 파일을 다시 가져오기 | 두 번째 가져오기에서 t001은 skipped로 집계되고 New Pool에 중복 추가되지 않음 |
| TC-CSV-03b | `csv-duplicate-ids.csv` | **파일 내부** 중복 id 처리(1회만 가져오기, 사전 이력 없음) | 이 파일을 처음 가져오는 상태에서 1회 가져오기 | ⚠️ 알려진 동작 확인용: `toNewPoolItems`는 `alreadyImportedIds`를 순회 중 갱신하지 않으므로 같은 파일 안의 중복 t001 두 행이 모두 New Pool에 들어갈 수 있음 — 실제 동작을 확인하고 기대와 다르면 버그로 기록 |
| TC-CSV-04 | `csv-missing-required-column.csv` | 필수 열("영어 문장") 누락 | 가져오기 시도 | `필수 열 "영어 문장"이 없습니다.` 오류 표시, 0행 가져옴 |
| TC-CSV-05 | `csv-blank-required-values.csv` | 필수 값(id/한글 문장/영어 문장) 공백 행 스킵 | 가져오기 시도 | t401만 가져와지고, id·한글 문장·영어 문장이 빈 3개 행은 각각 "N행: … 건너뜀" 오류로 보고되며 New Pool에는 포함 안 됨 |
| TC-CSV-06 | `csv-empty.csv` | 빈 파일 | 가져오기 시도 | `빈 파일입니다.` 오류 표시 |

### 체크리스트 실행 팁
- TC-CSV-03은 "가져오기 이력"이 있어야 재현되므로, 먼저 같은 파일을 1회 가져온 뒤 다시 같은 파일로 가져오기를 실행해야 한다.
- 오류 메시지 문구는 `apps/web/src/lib/csv.ts`의 `errors` 배열 문자열과 그대로 비교한다.
