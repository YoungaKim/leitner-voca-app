레이트너 앱이 읽어가는 **마스터 구글시트**에 신규 문장 100개를 이어붙인다.
시트 id: `19ZIqxOcAaaSMtH33s-Y6qSD76Pr-3eDKROq6RQMjNPM` (첫 번째 탭)

인수(`$ARGUMENTS`)가 있으면 그 주제/영역에 맞춰 생성하고, 없으면 아래 기본 구성을 따른다.

## 1. 현재 시트 상태 확인
- `scripts/` 의 서비스 계정으로 시트를 읽어 마지막 `sheet###` id를 확인한다.
  빠르게: `python3 -c "..."` 대신 그냥 [scripts/append_vocab.py](../../scripts/append_vocab.py) 가 쓰는 인증으로 `get_all_values()` 해서 max id 파악.
- 새 id는 마지막 번호 + 1 부터 100개 연속 (`sheet206` 형식, 3자리 유지).
- 기존 "청크·문법 메모"에 이미 나온 표현/문법 포인트는 **중복 금지** — 새 표현 위주로.

## 2. 문장 생성 (기본 구성, 총 100개)
[성적진단/영어-학습계획-1차.md](../../성적진단/영어-학습계획-1차.md) 의 4개 취약 영역을 이어서 심화한다.

| 영역 | 개수 | topic 예시 |
|---|---|---|
| 전치사·구동사 (동사+전치사, be+형용사+전치사) | 25 | 업무/계약/제품/고객 |
| 조건문·가정법 (if/unless/as long as/provided that/in case, 가정법 과거·과거완료, I wish, without) | 25 | 조건문/계약/업무 |
| 시제 일관성 (관계절·간접화법 시제 일치, had p.p.) | 20 | 업무/채용/고객 |
| 비교급 + 가정법 과거완료 결합 | 20 | 업무/제품/채용 |
| 토익 비즈니스 표현 (구동사·관용구) | 10 | 이메일/업무 |

- level: 대부분 B1, 가정법·비교급 복합문은 B2.
- 문장은 토익 파트5–7 빈출 상황 (업무/계약/제품/이메일/채용/고객/여행/행사).
- 한글 문장은 자연스러운 구어체, 영어 문장은 한 문장.

## 3. CSV 작성 & 시트에 추가
- 컬럼: `id,한글 문장,영어 문장,청크·문법 메모,level,topic,added_at`
- `added_at` 은 오늘 날짜 (YYYY-MM-DD).
- CSV 는 스크래치 경로에 저장 (프로젝트 안에 남기지 말 것). Python `csv` 모듈로 써서 콤마 이스케이프 처리.
- 실행: `python3 scripts/append_vocab.py <스크래치-csv경로>`
- 결과(추가 행 수, id 범위)를 한 줄로 알려준다.

## 4. 마무리
- 추가된 id 범위와 영역별 개수를 표로 요약.
- 앱에서 동기화하면 신규 문장만 Box1로 들어온다고 안내.
