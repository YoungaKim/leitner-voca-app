# 2026-08-27 17:14 회의록 — 텍스트 정답 입력 & AI 질문 기능 추가

## 논의 주제
- PC 웹 학습 화면에 (1) 텍스트로 정답 입력 + 오답 설명, (2) '선생님한테 질문' AI 아이콘 기능을 추가해달라는 요청으로 시작.
- 구현 후 실사용 중 발견된 여러 후속 이슈(Enter 키 채점 안 됨, TTS 목소리, AI API 키/할당량, 박스 스케줄링 동작 이해, 신규 카드가 시험부터 시작되는 문제 등)를 순차적으로 다룸.

## 진단 / 발견사항
- 기존 학습 세션은 자기채점([몰랐어]/[알았어])만 있었고, 오답 설명·AI 질문 기능이 전혀 없었음.
- 정답 확인 화면 전환 시 이전 포커스 대상이 사라져 포커스가 body로 빠지면서 Enter 키 채점이 안 되는 버그 발견.
- '선생님한테 질문' 최초 테스트 시 Gemini/GPT 모두 API 사용량/할당량 초과(429, insufficient_quota) — Gemini는 무료 티어 요청 한도, GPT는 결제수단 미등록이 원인.
- Supabase 실제 운영 DB에 `preferred_ai_model`, `input_method` 컬럼이 없어 새로고침마다 AI 모델 설정이 Claude로 초기화되던 버그 발견 → 로컬 `schema.sql`만 갱신되고 실제 DB엔 반영 안 된 것이 원인.
- TTS 목소리 품질 문제 — Chrome이 음성 목록을 비동기로 로드하는데 이를 기다리지 않고 재생해 저품질 기본 음성이 재생되던 문제.
- 사용자가 "박스1 카드가 다 외웠는데 안 넘어간다"고 문의 → 실제로는 신규 카드가 곧바로 박스1(테스트)로 승격되어 "학습" 단계 없이 바로 "시험"이 되는 구조적 문제였음. 라이트너 간격반복 원리(왜 오답을 당일 재반복 안 시키는지)에 대한 설명도 진행.
- 홈 화면 "내 상자 현황" 차트가 박스1~6+졸업 7칸만 그리도록 하드코딩돼 있어 새로 만든 박스0(신규) 카드가 차트에서 누락되던 것을 발견·수정. 이 수정이 한 차례 파일 롤백(다른 세션/에디터 자동저장 추정)으로 유실되어 재적용함.
- 콘텐츠 동기화가 시트의 새 문장을 곧장 카드로 만들지 않고 저수지(NewPool)에 쌓은 뒤 `newCap`만큼만 매일 도입하는 구조라, "동기화했는데 카드 수가 그대로"라는 문의에 대해 정상 동작임을 확인.
- `dailyGoal`(하루 목표)은 복습 개수 자체를 제한하지 않고, 복습 후 남는 여력만큼만 신규 카드를 들여오는 데 쓰이는 값임을 확인·설명(실제 복습 상한은 `reviewCap`).

## 결정 사항
- 텍스트 정답 입력은 기존 자기채점 버튼과 병행 제공, 관사/대소문자/구두점 차이는 정답으로 인정(`matchesAnswer`, LLM 미사용 규칙 기반).
- 오답 설명은 규칙 기반 word-diff만 사용(LLM 호출 없음), 카드의 청크 노트를 함께 노출.
- '선생님한테 질문'은 서버 프록시(Supabase Edge Function) + 앱이 관리하는 API 키 방식으로 구현, 사용자는 설정에서 Claude/Gemini/GPT 중 모델만 선택.
- AI 질문 기능은 카드 컨텍스트 기반 1회성 Q&A로 한정(대화 히스토리 없음).
- 신규 카드는 별도 학습 화면을 새로 만들지 않고, 기존 제시→힌트→정답확인→자기채점 화면을 그대로 재사용하되 **박스0**(복습 기한 없음)으로 도입 — 채점 결과와 무관하게 채점 후 무조건 박스1로 진입.
- 신규(박스0) 카드는 설정의 발음 자동재생 토글과 무관하게 항상 발음을 자동재생.
- Enter 키 전용 단축키(Space 제외)로 정답 확인, 정답 확인 후 자동으로 추천 채점 버튼에 포커스 부여.
- 코드 작성 전 항상 docs(01-PRD.md/02-DESIGN.md/03-UXUI.md) 먼저 갱신하는 방식으로 진행.
