## 진단 / 발견사항
- 학습 진행 상태는 계정(user_id)별 RLS로 완전 분리. 콘텐츠 시트만 공유되면 각자 독립 단어장 사용 가능
- AI 질문은 서버 프록시 + 앱 공용 키(Edge Function 시크릿) 구조 → 비용은 키 소유자(사용자 본인) 부담. 소비자용 Gemini 앱은 공개 API 없음, Gemini API는 프로젝트 단위 과금이라 "로그인 계정의 Gemini"는 구현 불가
- 무료로 각자 쓸 수 있는 건 Gemini(AI Studio 무료 키)뿐. Claude/OpenAI는 결제수단·선불 크레딧 필요
- 오늘 동기화 실패 원인: 설정에 "웹에 게시" 링크(/d/e/2PACX-…/pubhtml)를 입력. 현재 구조는 파일 ID가 든 공유 링크(/d/{ID}/edit) + content-sync-proxy(Sheets API v4) 필요. 코드 손상 아님
- 로컬 캐시가 비워졌던 건 계정 불일치로 clearAllLocal 추정. 클라우드 데이터(덱1·카드223)는 온전, 재로그인으로 복구됨
- contentSourceDeckId는 클라우드에 저장 안 되는 로컬 전용 값 → 캐시 비면 대상 덱 선택 소실
- 덱 삭제는 로컬·클라우드 양쪽 카드까지 cascade 삭제. syncState.importedIds는 안 지워져서, 삭제 후 같은 소스 재동기화하면 전부 스킵되어 새 덱이 빈다. 진도 복원 불가
