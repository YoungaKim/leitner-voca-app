# 2026-09-02 11:01 회의록 — 모바일 질문하기 버튼 키보드 가림

## 논의 주제
- 모바일에서 '질문하기' 기능 사용 시 텍스트 입력하면 '질문하기' 버튼이 키보드에 가려져, 키보드를 내려야만 누를 수 있음. 버튼 위치 이동이 필요한지 문의.
- 이어서: APK 재빌드 요청, 모바일 웹 접속 가능 여부/URL, 배포 없이 앱 사용 방법, 자동 업데이트 구성 방법.

## 진단 / 발견사항
- 웹앱(apps/web, React)과 안드로이드 앱(apps/android, 네이티브 Compose)은 완전히 별개 코드. 웹 수정은 폰 브라우저 접속 시에만 반영되고 APK에는 무관.
- 웹앱은 배포된 URL이 없음(호스팅 설정 없음). 로컬 Vite 개발 서버로만 구동.
- 네이티브 AskTeacherPanel.kt / StudySessionScreen.kt에 IME(키보드) 처리 누락 → 같은 증상.
- 자동 업데이트: 완전 무음 자동은 Play 스토어만 가능. 개발 편의 기준으로는 Firebase App Distribution이 가장 쉬움(앱 코드 거의 안 건드림, 명령 한 줄 배포).
- 기존 Firebase 프로젝트 device-streaming-984de832 존재(앱 없음) → 재활용.
- 로컬에 Java PATH 없음 → openjdk@17로 빌드(Android Studio 내장 JBR은 Java 25라 Gradle 비호환).
- 첫 App Distribution 업로드 실패: 프레임워크 아이콘(@android:drawable/ic_menu_edit)이 APK에 안 담겨 "APK does not contain an icon" → 자체 adaptive 아이콘 추가로 해결.

## 결정 사항
- 모바일 웹 배포는 불필요. 안드로이드는 APK(네이티브)로 사용.
- 키보드 문제는 웹·네이티브 양쪽 모두 수정: 입력창의 키보드 확인/전송 키로 바로 제출 + 화면 스크롤 보정.
- 배포는 Firebase App Distribution 사용. release 서명 키 신규 생성, git 제외.
- versionCode는 git 커밋 수로 자동 증가.
